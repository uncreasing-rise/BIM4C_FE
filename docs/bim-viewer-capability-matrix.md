# BIM 3D viewer capability matrix

## Implemented in the browser

- Loads the public IFC demonstration automatically and accepts additional IFC uploads.
- Parses IFC in a Web Worker with `web-ifc`, preserving geometry, spatial hierarchy, property sets, materials, quantities and coordinate metadata.
- Federates multiple IFC files with shared/origin alignment and manual offsets.
- Orbit, perspective, top, front, right and isometric views, fit-all and fit-selection.
- Element picking, Ctrl/Shift multi-selection, property inspection and spatial path inspection.
- Model search/filter by filename, name, IFC type, GUID, material, property sets, discipline and storey. Spatial tree follows IFC ancestry, mounts children on expansion and loads element rows in batches of 100 without truncating results.
- Hide selected element, isolate selected element and restore visibility.
- Section box, explode view, discipline visibility, surface snapping, distance/point measurements and CSV export.
- PNG snapshot, fullscreen mode, diagnostics and cancellation during IFC loading.
- Browser-local saved viewpoints capture camera position/target/up/FOV, section box, element visibility, discipline layers, selection and explode. Model placement/visibility and scene identity are not yet captured.
- Session persistence and validated JSON export/import; sessions are not yet scoped to a model fingerprint, so reopening a different file set is not a supported restoration workflow.
- New measurements keep model-local anchors, follow manual model placement changes and are removed when their model is removed. Measurements are hidden during explode; entering the measurement tool resets explode.
- Browser-local AABB clash candidate checking across disciplines.
- Browser-local issue notes linked to the current element selection.
- Automated unit/integration coverage for IFC parsing, federation, snapping, section clipping and viewer wiring.

## Not generated by the current frontend

- Clash detection: the viewer now has a fast local AABB candidate pass, but it is approximate and may produce false positives. Exact BRep/mesh intersection, robust tolerances and production coordination results still require a stronger geometry engine or precomputed service.
- Issues/BCF: local issue notes exist; BCF ZIP import/export, viewpoint pins, comments, assignees and attachments are not implemented. Offline BCF does not inherently require a backend.
- Revit/RVT, NWD/NWC, DWG/DXF and point clouds: require format-specific conversion services; Autodesk APS is the likely route for Autodesk formats.
- Saved viewpoints, measurements and visibility sets across users: require project/version persistence.
- Realtime collaboration, permissions and audit history: require authentication, authorization, backend storage and websocket/event infrastructure.
- Very large-model streaming/LOD/instancing: requires production IFC benchmarks and a renderer/data pipeline designed around spatial tiling.

## Other missing viewer capabilities

- Polygon area, diameter and polyline measurement; configurable units and precision. Three-point angle (at the second point) and 3D triangle area are implemented, including CSV and local session serialization; degenerate angles display an em dash.
- Orthographic projection, navigation cube, walk mode, box/lasso selection and reusable selection sets.
- Virtualized large-model browsing, section caps and vector section export.
- Canvas snapshots currently omit HTML measurement labels.
- Browser interaction and large-model performance validation remain necessary beyond automated tests.

The current clash list is an approximate candidate review surface, not an exact clash-detection engine. Do not advertise Autodesk feature parity. Many missing viewer capabilities can be implemented entirely locally; proprietary format conversion and shared collaboration have separate requirements.
